# QR Code Generator Website

A responsive and modern web application for generating QR codes from URLs and website links. Features a clean UI design and an about us page for team members.

## Features

- **QR Code Generation**: Convert any URL or website link into a QR code instantly
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Download Functionality**: Download generated QR codes as PNG images
- **Modern UI**: Beautiful gradient design with smooth animations
- **About Us Page**: Showcases team members with social links
- **Real-time Validation**: URL validation with instant feedback
- **Keyboard Support**: Generate QR codes using Enter key
- **Smooth Scrolling**: Navigation with smooth scroll effects

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with gradients, flexbox, and grid layout
- **JavaScript**: Interactive functionality and QR code generation
- **QRCode.js**: Library for QR code generation
- **Font Awesome**: Icons for enhanced UI
- **Google Fonts**: Typography

## Installation & Usage

1. Clone or download the project files
2. Open `index.html` in a web browser
3. Enter a valid URL in the input field
4. Click "Generate QR" or press Enter
5. Download the generated QR code using the download button
